# NcCycleSense

NC 程式的加工週期時間預估。NC 碼不會離開你的電腦。

線上版免安裝，拖檔案進去就算：<https://nccyclesense.com>

## 下載

最新版在 [Releases](https://github.com/ming0393639/NcCycleSense-releases/releases/latest)。

Windows 10 / 11（64 位元），安裝在 `%LOCALAPPDATA%\NcCycleSense\`，不需要管理員權限。
安裝檔尚未做程式碼簽章，Windows 會顯示「不明的發行者」，選「其他資訊」→「仍要執行」。

裝好之後有兩個程式：`NcCycleSense.exe`（介面）與 `nccs.exe`（命令列）。

## 版本
