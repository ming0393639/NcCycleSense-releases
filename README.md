# NcCycleSense

NC 程式的加工週期時間預估。NC 碼不會離開你的電腦。

線上版免安裝，拖檔案進去就算：<https://nccyclesense.com>

## 尚未發行

桌面版**開發中，還沒有可以下載的版本**。發行之後安裝檔會出現在
[Releases](https://github.com/ming0393639/NcCycleSense-releases/releases)。

在那之前請用線上版，引擎是同一份。

## 版本

發行之後每一版都會留在這一頁。授權的更新期比對的是版本的發行日，
所以舊版隨時取得得到。

## 授權

桌面版不匯入啟用檔就能用，限制與線上版相同：完整引擎、單支程式、
10 MB 上限、報告帶浮水印。授權解除上限與浮水印，並開放多工序加總與批次。
啟用檔匯入後在本機驗證，不需連網。

取得方式見 <https://nccyclesense.com/pricing.html>。

## 原始碼不在這裡

這個 repo 只放安裝檔。引擎的可稽核性說明在
<https://nccyclesense.com/legal.html#audit>。
